# Code of Conduct

This project is a technical collaboration space. Contributors are expected to keep discussion direct, respectful, and focused on the work.

## Expected Behavior

- Be precise and constructive in code review.
- Critique technical decisions, not people.
- Ask for evidence when claims are unclear.
- Keep provider limitations and security risks visible instead of overstating maturity.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing private credentials, tokens, datasets, or exploit details.
- Repeatedly misrepresenting project capabilities after maintainers correct the status.
- Spam or unrelated promotion.

## Enforcement

Maintainers may edit or delete comments, close issues, reject contributions, or block participants who violate this code of conduct. Serious security issues should be handled through `SECURITY.md`, not public argument.
